# Developer Goals

## My Goals for the 8 Weeks

During the 8 weeks of Averon Academy, I want to build a strong foundation in software development and become more confident using development tools. I want to understand how to approach problems logically, write clean and useful code, and complete practical projects.

## The Type of Developer I Want to Become

I want to become a skilled and creative full-stack developer who can build useful, accessible, and user-friendly applications. I want to be able to understand both the frontend and backend sides of development and use technology to solve real-life problems.

## Three Technical Skills I Want to Learn

1. HTML, CSS, and JavaScript for web development.
2. Git and GitHub for version control and collaboration.
3. Backend development and working with databases.

## My Long-Term Goal in Technology

My long-term goal is to become a professional software developer and use technology to create solutions that can make people's lives easier. I also want to combine technology with my knowledge of geography and other areas of interest to develop innovative solutions to real-world problems.
