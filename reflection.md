# Week 1 Reflection

## 1. What did I learn this week?

This week, I learned the basics of software development and the role of a software developer. I learned about frontend, backend, and full-stack development. I also learned about Git, GitHub, repositories, commits, branches, and the basic Git workflow.

I learned how developers use Git and GitHub to track, manage, store, and share their work.

## 2. What was difficult for me?

The most difficult part for me was understanding some of the Git concepts and how the different Git commands work together. At first, concepts such as repositories, commits, staging, and pushing code were a little confusing.

## 3. How did I solve the problem?

I solved the problem by following the instructions step by step, practicing the commands, and taking my time to understand what each step does. I also used VS Code and GitHub practically instead of only reading about them.

## 4. What do I still need help with?
